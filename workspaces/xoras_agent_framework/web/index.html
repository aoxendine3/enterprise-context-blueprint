Developer Quickstart

Deploy the XORAS Agentic Framework into any codebase in seconds.

# 1. Install XORAS Agent Framework
pip install xoras-agent-framework
# 2. Initialize .xorasrules and xoras.env.yaml
xoras init
# 3. Scan scripts for AST security violations
xoras scan my_agent_script.py
# 4. Launch isolated sandboxed execution harness
xoras run my_agent_script.py
