# Cryptographic Evidence Receipts (`xoras.evidence.v1`)

## Overview
Every operational trace generated by `xoras.runtime` is cryptographically signed using HMAC-SHA256 / Ed25519 signing envelopes.

## Receipt Schema
```json
{
  "version": "xoras.evidence.v1",
  "timestamp": 1791514104.972051,
  "organization": "XORAS Systems LLC",
  "agent": "Engineer",
  "action": "file_write",
  "payload": {
    "path": "artifacts/status.json",
    "content": "{\"status\": \"active\"}"
  },
  "payload_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "status": "SUCCESS",
  "signature": "y+x/Ft1TqiNbJpGD32ECqnJhlsM9JzAYhvWVPPSkfUk="
}
```

## Envelope Construction
$$\text{Envelope} = \text{"XORAS\_V1"} \parallel \text{timestamp} \parallel \text{agent\_id} \parallel \text{action} \parallel \text{payload\_hash} \parallel \text{status}$$
The envelope is signed with the workspace secret key, guaranteeing tamper-evident audit trails.
