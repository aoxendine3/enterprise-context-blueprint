Architectural Root Cause: External Memory Dereference vs Atomic Trap

User-space supervisors must read process arguments out-of-band across IPC via /proc/$PID/mem. This creates a multi-microsecond race window where an un-trapped concurrent thread overwrites the approved payload pointer before syscall execution. UPGP evaluates registers atomically inside the Linux kernel BPF engine with zero userland memory in the path.
