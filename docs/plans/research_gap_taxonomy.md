# Research‑Gap Taxonomy (Miles 2017, 2021)

The collective adopts the **seven‑point taxonomy** as the canonical lens for identifying missing knowledge, evidence, or methodology. It is stored in the SSOT repository for reference by every agent, sub‑agent, and downstream tool.

| Rank | Gap Type (Common Name) | Formal Name | Core Focus |
|------|------------------------|-------------|------------|
| 1️⃣ | **Population Gap** | Under‑Researched Sub‑Groups Gap | Identify demographic or contextual sub‑populations that are under‑represented in the evidence base. |
| 2️⃣ | **Empirical Gap** | Evaluation Void Gap | Test unverified propositions with direct quantitative or experimental evaluation. |
| 3️⃣ | **Methodological Gap** | Methodology Void Gap | Apply a divergent research design or instrument to a problem previously explored with a single method. |
| 4️⃣ | **Knowledge Gap** | Knowledge Void Gap | Investigate topics where **no** empirical data or literature currently exists. |
| 5️⃣ | **Theoretical Gap** | Theory Application Void Gap | Develop or import a theoretical framework to explain an observed phenomenon. |
| 6️⃣ | **Evidence Gap** | Contradictory Evidence Gap | Reconcile conflicting findings from well‑designed studies on the same subject. |
| 7️⃣ | **Practical‑Knowledge Gap** | Action‑Knowledge Conflict Gap | Align professional practice with academic recommendations (or expose where they diverge). |

**Historical Foundations**

* **Robinson et al. (2011)** – PICO‑style systematic‑review axes (Population, Intervention, Comparison, Outcomes, Setting).  
* **Müller‑Bloch & Kranz (2014)** – Extended to six dimensions (Contradictory Evidence, Knowledge Void, Action‑Knowledge Conflict, Methodological, Evaluation Void, Theory Application Void).  

The **Miles taxonomy** merges these into a single, ranked, seven‑point framework that the Collective now uses to **systematically surface and prioritize research gaps** across all domains (finance, compliance, AI governance, etc.).

*All agents should reference this file when performing gap analyses, building golden‑question sets, or drafting new study proposals.*
