### 2.1 The Mathematical Formalism of Monotonic Ranks ($\sigma$)
Let a swarm $\mathcal{S}$ consist of $N$ concurrent agents $\{A_1, A_2, \dots, A_N\}$. Each agent $A_i$ is assigned a static or dynamically computed monotonic serialization rank $\sigma(A_i) \in \mathbb{N}$:
$$\sigma(A_i) < \sigma(A_j) \implies \text{Priority}(A_i) < \text{Priority}(A_j)$$

When concurrent agents generate conflicting state mutations over the shared state space $\Omega$, MTPO guarantees **zero transaction aborts** through monotonic serialization ordering:
1. All read/write trajectories form a Directed Acyclic Graph (DAG) ordered by $\sigma$.
2. Write operations are committed into lock-free atomic double-buffered slots without mutex contention.

### 2.2 The Three-Phase Saga Undo Inverse Protocol
Instead of blocking or aborting upon speculative collision, the engine executes a three-phase Saga protocol:
1. **Prepare Phase ($\mathcal{P}$):**
   Agent $A_i$ hashes the proposed state delta $\Delta_i$ using SHA-256:
   $$h_i = \text{SHA256}(\Delta_i)$$
   The delta is logged in an in-memory atomic WAL and broadcast via an advisory notification $\nu_{i \to j}$.
2. **Execute Phase ($\mathcal{E}$):**
   The delta is merged into the active memory topology (e.g., `HexCell` contiguous 3,200-byte stride). Higher-rank transactions take precedence in conflict resolution.
3. **Reverse Phase ($\mathcal{R}$):**
   If an out-of-order dependency collision occurs with a higher-rank agent $A_j$ ($\sigma(A_j) > \sigma(A_i)$), $A_i$ does **not** fail. Instead, the engine applies the deterministic inverse function:
   $$\Omega_{t+1} = \Omega_t \oplus \Delta_i^{-1}$$
