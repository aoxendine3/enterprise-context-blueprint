The REASONS Canvas: Compiling Human Intent into Graph Specifications

Under Structured-Prompt-Driven Development (SPDD), prompting in raw natural language is rejected in favor of the REASONS Canvas. The Conductor compiles requirements into an acyclic Intent Graph (DAG). If cyclic dependencies or ambiguous execution paths occur, execution halts immediately with an EpistemicAnomalyException before a single GPU token is wasted.

1. How Atlan Measures Hallucination

Atlan treats hallucination as an enterprise context failure. Grounding agents in a unified metadata context layer with graph-based retrieval (GraphRAG) cuts hallucination by over 40% and boosts query accuracy from 9% to 81% in production.

• Groundedness Score (%)
[Verified Evidence-Backed Claims / Total Claims Generated] × 100. Directly separates evidence execution from pre-training statistical guesses.
• Retrieval Quality (Precision & Recall)
Evaluates fraction of retrieved context that is relevant (Precision) and relevant context retrieved (Recall).
• Use-Case Risk-Tiered Hallucination Rate
High-Risk (Finance/Core): < 5% (mandatory HITL). Medium-Risk: < 10%. Low-Risk: 20%–30%.
• User Trust Signals
Tracks suggestion acceptance and override volume. Below an 80% accuracy threshold, trust collapses non-linearly.
• Decision Tracing & Context Studio Runs
Logs column-level lineage to world_file.db and runs pre-deployment simulation over Golden Question Sets.
